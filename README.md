# 斩鬼录 · Demon Slayer

PC 端 Web 回合制卡牌游戏，灵感来自《杀戮尖塔》：选职业、购卡、合成升星、打怪通关。

技术栈：**Vue 3 + Pinia + Vue Router + JavaScript + Vite**

---

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 `http://localhost:5173/`）。

| 命令 | 说明 |
|------|------|
| `npm run dev` | 本地开发 |
| `npm run build` | 生产构建 |
| `npm run preview` | 预览构建结果 |

## 游戏目标

从第 **1** 层打到第 **10** 层，击败最终 Boss **百目鬼王** 即通关。

中途阵亡会结算本局进度（用于解锁职业），可重新选择职业再开一局。

---

## 核心玩法

### 1. 选择职业

开局选择一个已解锁职业，各自有不同的生命、能量、起步金币、每回合产金与初始卡组。

### 2. 回合流程

每一战斗回合大致如下：

1. **自动获得金币**（基础产金 + 层数加成）
2. **商店刷新** 3 张可购买卡牌
3. **抽牌** 到手牌（默认 5 张），回复满能量
4. **出牌**：点击手牌消耗能量，对敌人造成伤害 / 获得护甲 / 治疗等
5. 点击 **结束回合** → 手牌弃置 → **敌人行动** → 进入下一回合

护甲只在当回合有效，下回合开始时清空。

### 3. 卡牌购买

- 右侧 / 中部 **卡牌市集** 每回合提供 3 张货
- 金币足够即可购买，购入后加入卡组
- 可花费金币 **刷新** 商店（费用随层数上涨）
- 层间休整阶段仍可继续买牌、合成，再进入下一层

### 4. 卡牌合成（升星）

- **3 张同名、同星** 卡牌 → 合成为 **1 张高 1 星** 的同名卡
- 最高 **3 星**（★★★）
- 星级越高，卡牌数值倍率越高
- 购买后若满足条件会 **自动合成**；也可打开「合成一览」手动合成

| 星级 | 数值倍率（约） |
|------|----------------|
| ★ | 1× |
| ★★ | 1.75× |
| ★★★ | 2.75× |

### 5. 战斗与层数

- 每层遭遇一只敌人；部分层为 **精英**，第 10 层为 **Boss**
- 击杀后获得金币奖励，并少量回血，进入层间休整
- 生命归零则本局失败

## 职业一览

| 职业 | 定位 | 解锁条件 |
|------|------|----------|
| **剑士** | 均衡近战，起步稳 | 初始解锁 |
| **咒术师** | 咒术与灼烧，偏输出 | 历史最高抵达第 **5** 层 |
| **影刃** | 低血高爆发 | 累计通关 **2** 次 |
| **御盾** | 厚血高防、反伤 | 累计通关 **4** 次 |

进度保存在浏览器 `localStorage`，刷新页面不会丢失解锁记录。

## 界面说明

| 区域 | 内容 |
|------|------|
| 顶部状态栏 | 职业、层数、回合、生命 / 护甲、金币、能量、卡组数量 |

## 小提示

- 优先合成常用攻击 / 防御牌，星级提升收益很大。
- 留够金币应对精英与 Boss；层数越高敌人越硬。
- 护甲能大幅降低回合末承伤；御盾职业尤其依赖格挡与反伤。
- 想解锁其他职业：先用剑士多推层、多通关。
