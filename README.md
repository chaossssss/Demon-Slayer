# 斩鬼录 · Demon Slayer

PC 端 Web 回合制卡牌游戏（灵感来自《杀戮尖塔》）：

**选职业 → 购卡合成升星 → 通关选宝物 → 打到第十层**

| 项 | 说明 |
|----|------|
| 技术栈 | Vue 3 + Pinia + Vue Router + JavaScript + Vite |
| 平台 | PC Web（推荐桌面浏览器） |
| 开发端口 | `http://localhost:9530/` |
| 主题调性 | 斩鬼 / 和风暗色纸本：炭黑底、宣纸色面板、朱红血色、鎏金点缀 |

---

## 快速开始

```bash
npm install
npm run dev      # http://localhost:9530/
npm run build
npm run preview
```

进度保存在浏览器 `localStorage`（键名：`demonslayer_progress`）。

> **测试说明**：当前为方便测试，**四职业全部解锁**。正式上线前需改回进度解锁（见 `src/stores/progress.js` / `src/data/gameData.js` 中的 TODO）。

## 一、游戏目标与流程

### 目标

- 从 **第 1 层** 打到 **第 10 层**
- 第 10 层击败 Boss **百目鬼王** → **通关胜利**
- 中途生命归零 → **失败**，仍结算最高层数 / 通关次数（用于解锁职业）

### 玩家流程（页面）

```
首页 (/) → 选择职业 (/class) → 战斗 (/battle)
                ↑                    │
                └──── 再选职业 / 回首页 ◄─┘（胜负结算后）
```

### 单局战斗循环

```
进入本层 → 生成敌人（第 3/6 层 2 只、第 5/7 层 3 只）→ 开始回合
  ├─ 自动加金币（含宝物加成）
  ├─ 进层 / 每回合开始刷新商店 3 张牌（若未锁定）
  ├─ 回满能量；发一星牌（第 1 层开局 5 张，之后每回合 2 张；未打出的保留，上限 10）
  ├─ 玩家出牌（多目标需点选）/ 买牌 / 合成 / 锁市集
  └─ 结束回合 → 存活敌人依次行动 → 下一回合（手牌不弃置；市集未锁定则刷新）
击杀全部敌人
  ├─ 金币奖励
  ├─ 【宝物三选一】（可放弃）← 新增
  └─ 休整回血 + 市集买牌 → 下一层
… 直到第 10 层 Boss 或阵亡
```

## 三、核心规则详解

### 3.1 资源

| 资源 | 说明 |
|------|------|
| 生命 | 归零失败；通关休整会回血（可被宝物加强） |
| 护甲 | 抵伤；**每回合开始清空**（宝物「回合初护甲」会再挂上） |
| 能量 | 出牌消耗；每回合回满 |
| 金币 | 买牌、刷新；每回合自动获得 |
| **宝物** | 本局永久持有，效果持续叠加 |

每回合产金（含宝物）：

```
income = max(0, goldPerTurn + 宝物产金) + floor((层数-1)/2)*2 + 宝物回合初金币
```

刷新商店：`8 + 层数`（市集锁定时不可刷新）。  
击杀奖励：`18 + 层数×6`，精英 +20，Boss +50。

### 3.2 卡牌市集

- 进入本层、**每回合开始**、休整时刷新 **3** 张（未锁定时）
- 仅当前职业卡池；稀有度权重 60 / 30 / 10
- 售价 ≈ 基础价 + 层数×1.5 + **宝物价格修正**
- 购入进卡组；战斗中若手牌未满则同时进手牌
- **锁定市集**：结束回合 / 过关休整都不刷新货架；锁定期间不能手动刷新
- 满 3 张同名同星会 **自动合成**

### 3.3 手牌逻辑

| 项 | 规则 |
|----|------|
| 手牌上限 | **10** 张 |
| 结束回合 | **不弃置**未打出的手牌，原样保留到下回合 |
| 回合开始 | 回满能量后，从抽牌堆 / 弃牌堆发放 **一星** 牌（费用不限；不含 ★★ / ★★★；受上限限制） |
| 第 1 层开局 | 发放 **5** 张一星牌 |
| 其后每回合 | **新生成** **2** 张一星牌加入卡组与手牌（不从弃牌回收；手牌满 10 张则不发，战报会提示）；未打出的手牌保留 |
| 出牌 | 打出的牌进入弃牌堆 |
| 卡牌抽牌效果 | 仍可额外抽牌，同样不超过手牌上限 |
| 买牌（战斗中） | 进卡组；手牌未满时同时进手牌 |
| 合成（战斗中） | 升星牌在手牌未满时进手牌 |
| 进入新一层 | 手牌 / 抽牌 / 弃牌清空，卡组洗入抽牌堆；第 1 层开局发 5 张一星，第 2 层起进层首回合发 2 张一星 |
| 通关本层 | 手牌与战斗牌堆清空，进入宝物 / 休整 |

牌堆流转：

```
卡组 deck（本局持有）
  └─ 进层时洗入 → 抽牌堆 drawPile
       ├─ 回合开始：新生成一星牌进手（第 1 层开局 5，之后每回合 2；手牌满则跳过）
       ├─ 卡牌效果抽牌 → 手牌
       └─ 打出 → 弃牌堆 discard
            └─ 抽牌堆空时，弃牌洗回抽牌堆
```

常量（`src/data/gameData.js`）：`HAND_SIZE = 10`，`TURN_START_STAR1_CARDS = 2`，`FLOOR1_START_STAR1_CARDS = 5`。

### 3.4 合成升星

- 3 张**不同**同名同星卡（按卡牌 uid 计）→ 1 张高 **1** 星；最高 ★★★
- 自动/手动合成都 **只升一层**（3×★ → ★★ 后，不会在同一次操作里再合成 ★★★）
- 开局 **不** 自动合成
- ★ / ★★ / ★★★ 倍率约 ×1 / ×1.75 / ×2.75
- ★★★ 解锁该卡 **专属大招**（打出时额外触发）

### 3.5 宝物系统（通关奖励）

**触发**：每层击杀敌人后（最终通关胜利不再选）。  

**规则**：

1. 从宝物池随机出 **3** 件（已拥有的不会再出）
2. **选 1 件** 或 **放弃**
3. 随后进入休整市集
4. 精英层更容易刷出宝器 / 咒物；高层略降低凡品权重

**等级**：

| 等级 ID | 中文 | 权重 | 特点 |
|---------|------|------|------|
| `common` | 凡品 | 50 | 小幅稳定增益 |
| `uncommon` | 灵品 | 28 | 较强增益 |
| `rare` | 宝器 | 14 | 强力增益 |
| `cursed` | 咒物 | 8 | **增益 + 负面** 并存 |

**效果类型**（可正可负，多件叠加）：

| 字段 | 含义 |
|------|------|
| `maxHp` | 最大生命（获得时立即按差值调整当前生命） |
| `maxEnergy` | 最大能量 |
| `goldPerTurn` | 回合产金 |
| `damageFlat` | 所有伤害加成 |
| `blockFlat` | 获得护甲时加减 |
| `burnFlat` | 施加灼烧加减 |
| `healFlat` | 治疗加减 |
| `thornsFlat` | 回合开始反伤 |
| `startBlock` | 回合开始护甲 |
| `turnStartGold` | 回合开始额外金币 |
| `turnStartHpLoss` | 回合开始掉血（咒物） |
| `turnStartHpHeal` | 回合开始回血 |
| `damageTakenFlat` | 额外承伤 |
| `shopPriceFlat` | 商店价格加减 |
| `floorClearHeal` | 通关休整额外回血 |
| `lifesteal` | 造成伤害后按比例吸血 |

配置文件：`src/data/treasures.js`

### 3.6 战斗关键字

伤害、护甲、灼烧、反伤、抽牌、能量、治疗、穿透、削弱、处决加成、多段 hits（含义同前版）。

### 3.7 层数与敌人

- 共 10 层；第 10 层 Boss  
- **多怪层**：第 3 / 6 层各 **2** 只普通怪，第 5 / 7 层各 **3** 只普通怪（多怪层数值 ×0.72）  
- 其余层仍为单怪；非多怪且层数能被 3 整除时为精英（如第 9 层）  
- 敌人数值：`× (1 + (层数-1)×0.18)`（多怪再乘 0.72）  
- 手牌规则见 **3.3**；存活敌人依次行动  
- **多目标**：部分卡需点选敌人；多怪时需手动点选目标
