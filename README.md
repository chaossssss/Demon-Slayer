# 斩鬼录 · Demon Slayer

PC 端 Web 回合制卡牌游戏（灵感来自《杀戮尖塔》）：选职业 → 购卡 → 三合升星 → 三星解锁大招 → 通关十层鬼域。

| 项 | 说明 |
|----|------|
| 技术栈 | Vue 3 + Pinia + Vue Router + JavaScript + Vite |
| 平台 | PC Web（推荐桌面浏览器） |
| 开发端口 | `http://localhost:9530/` |
| 主题调性 | 斩鬼 / 和风暗色纸本：炭黑底、宣纸色面板、朱红血色、鎏金点缀 |

---

## 快速开始

```bash
npm install
npm run dev      # http://localhost:9530/
npm run build
npm run preview
```

进度保存在浏览器 `localStorage`（键名：`demonslayer_progress`）。

## 一、游戏目标与流程

### 目标

- 从 **第 1 层** 打到 **第 10 层**
- 第 10 层击败 Boss **百目鬼王** → **通关胜利**
- 中途生命归零 → **失败**，仍结算最高层数 / 通关次数（用于解锁职业）

### 玩家流程（页面）

```
首页 (/) → 选择职业 (/class) → 战斗 (/battle)
                ↑                    │
                └──── 再选职业 / 回首页 ◄─┘（胜负结算后）
```

### 单局战斗循环

```
进入本层 → 生成敌人 → 开始回合
  ├─ 自动加金币
  ├─ 商店刷新 3 张牌
  ├─ 抽 5 张手牌、回满能量
  ├─ 玩家出牌（可买牌 / 合成）
  └─ 结束回合 → 敌人行动 → 下一回合
击杀敌人 → 金币奖励 + 少量回血 → 层间休整（可继续买牌）
  └─ 进入下一层 … 直到第 10 层 Boss 或阵亡
```

## 三、核心规则详解

### 3.1 资源

| 资源 | 说明 |
|------|------|
| **生命 HP** | 归零失败；层间击杀后少量回复 |
| **护甲 Block** | 抵消伤害；**每回合开始清空** |
| **能量 Energy** | 出牌消耗；每回合回满（职业上限 3 或 4） |
| **金币 Gold** | 买牌、刷新商店；每回合自动获得 |

每回合产金公式：

```
income = goldPerTurn + floor((层数 - 1) / 2) * 2
```

刷新商店费用：`8 + 当前层数`。

击杀奖励（约）：`18 + 层数×6`，精英 +20，Boss +50。

### 3.2 商店

- 每回合刷新 **3** 张牌（`SHOP_SIZE = 3`）
- 只出现**当前职业可购**卡池
- 稀有度权重：普通 60 / 优秀 30 / 稀有 10
- 售价 ≈ 基础价 + `层数 × 1.5`
- 购入即进卡组；战斗中购入还会进手牌
- 满足 3 张同名同星时 **自动合成**

### 3.3 合成升星

- **3 张同名 + 同星** → **1 张星级 +1**
- 最高 **3 星**
- 开局不自动合成；购入后满 3 张同名同星才会合成
- 可在「合成一览」查看每张牌 `x/3` 进度并手动合成

| 星级 | 基础数值倍率 | 额外 |
|------|--------------|------|
| ★ | ×1 | — |
| ★★ | ×1.75 | — |
| ★★★ | ×2.75 | **解锁专属大招**（打出时先结算普通效果，再追加大招） |

### 3.4 战斗关键字

| 关键字 | 含义 |
|--------|------|
| 伤害 | 扣敌人生命（先扣其护甲，除非穿透） |
| 护甲 | 抵消受到的伤害 |
| 灼烧 | 每回合开始对敌人造成等同层数的伤害，然后 -1 层 |
| 反伤 | 敌人攻击你时，先受到反伤伤害 |
| 抽牌 | 从抽牌堆补牌（空则洗入弃牌） |
| 能量 | 增加本回合可出牌费用 |
| 治疗 | 回复生命（不超过上限） |
| 穿透 | 忽略敌人护甲直接扣血 |
| 削弱 | 永久降低该敌人攻击力（本场） |
| 处决加成 | 敌人低于半血时额外伤害 |
| 多段 hits | 同一伤害结算多次 |

### 3.5 层数与敌人缩放

- 共 **10** 层（`FLOORS_TO_WIN = 10`）
- 每 3 层出现 **精英**（非 Boss 层）
- 第 10 层 **Boss**
- 敌人生命/伤害随层数：`× (1 + (层数-1)×0.18)`
- Boss 每 3 回合意图伤害约 ×1.4

手牌上限抽牌数：每回合抽 **5** 张（`HAND_SIZE`）。
