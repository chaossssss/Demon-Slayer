# 技能战斗动画提示词

给文生视频用，但目标是 **回合制卡牌的战斗技能动画**，不是影视短片、不是预告片。

战场布局：玩家在左、敌人在右（与 `/arena` 一致）。生成后裁切/抠像叠到角色槽上。

---

## 制作规格（每条都必须遵守）

| 项 | 规定 |
| --- | --- |
| 画幅 | 16:9 |
| 时长 | 普通技 **2 秒**；三星大招 **3 秒**；被动吸血 **1 秒** |
| 机位 | **固定机位，禁止推拉摇移环绕** |
| 构图 | 侧面全身；角色脚踩同一地平线；人物约占画面左 35% |
| 朝向 | 角色面朝右（朝敌人） |
| 首尾 | 第 1 帧、最后 1 帧都是 **侧面站桩待机**，方便接 idle |
| 背景 | 纯炭黑 `#1c1712`，地面一条淡鎏金圆形法阵即可；不要荒园、飞檐、满月、复杂场景 |
| 受击靶 | 攻击技：画面右侧放 **1 只简化小鬼剪影**（多目标则 2～3 只一字排开），不抢戏、不走位 |
| 自buff | 格挡/治疗/回能：**右侧不放敌人** |
| 特效 | 轮廓清晰、色彩对比强，缩小到 120px 仍能看懂 |
| 动作 | 游戏演出：快起快收，不要电影慢镜头、不要情绪特写 |

## 一、全职业共用（四职业都要出，动画必须一样）

> 这是公共技能。四条只换角色外观，**抬手、时间轴、特效形状/颜色必须相同**。  
> 不要改成剑气、符火、烟刃或实体盾。御盾的玄武盾只背在身侧，不参与这套动画。

## 落地用法

1. **角色动画** 与 **特效** 能拆就拆：先出带角色的成片，再单独出「纯特效、无角色、炭黑底」方便叠层。
2. 炭黑底可抠像；若模型抠不干净，改成 **纯绿幕 `#00FF00`**，其余提示词不动。
3. 同一职业批量出时，把该职业「出演」句原样贴进每条，站位才齐。
4. 导入游戏后：左裁角色槽、右裁受击槽；普通 2 秒可 1.2～1.5 倍速播。
5. 共用技能四职业必须同一套时间轴，方便战斗里播同一条 VFX、只换人物层。
